1. Project Overview & Title

Project Title: Mitigating Cognitive Offloading in AI-Assisted Learning: An Empirical Study of Socratic Scaffolding vs. Direct LLM Response
Domain: Generative Artificial Intelligence (GenAI) / Intelligent Tutoring Systems (ITS)
Sub-Area: Pedagogical Alignment, Guardrail Engineering, Cognitive Load Theory, Computing Education

2. Introduction & Background

The mainstream deployment of foundational Large Language Models (LLMs) across higher education has transformed how students approach computing and data science assignments. However, commercially deployed LLMs are optimized as direct question-answering engines. When students submit coding exercises or data transformation tasks, the model outputs ready-to-run scripts and complete mathematical derivations immediately.

This unconstrained automation triggers acute cognitive offloading—the habit of bypassing metacognitive struggle in favor of copy-pasting automated outputs. Educational psychology, guided by Sweller's Cognitive Load Theory, demonstrates that deep schema acquisition requires germane cognitive load (deliberate mental struggle). When students offload this reasoning loop, they develop a superficial "competence illusion" while losing foundational debugging, syntax reasoning, and analytical problem-solving skills.

3. Problem Statement

Existing AI coding assistants lack pedagogical boundaries. In programming and STEM domains, standard LLMs exhibit an **Answer Leakage Rate approaching 100%**, directly supplying complete code blocks, return statements, and mathematical solutions. Consequently, there is an urgent need for an automated, lightweight pedagogical framework that:

  • Prevents premature solution leakage and detects student attempts to solicit complete code.
  • Statically inspects student code across multiple languages (C, C++, Python, Data Science) to identify syntax, scoping, and logic bugs without handing out answers.
  • Maintains multi-turn context memory and actively verifies student reasoning and answers.

4. Objectives of the Project

  1. Develop SocraticGuard: An anti-cheating pedagogical guardrail framework replacing direct code answers with an active Socratic reasoning loop.
  2. Implement Multi-Language Static Code Analysis: Create dedicated inspection engines for:
    • C/C++: Non-void return; errors, missing return 0; in main(), print vs printf, format specifier mismatches, unclosed braces, and uninitialized variables.
    • Python: Abstract Syntax Tree (AST) validation, mutable default arguments, bare exceptions, and unbounded recursion.
    • Data Science: Data leakage detection (fitting scalers on test data) and Pandas in-place reassignment bugs.
  3. Establish Progressive 3-Tier Scaffolding:
    • Tier 1 (Conceptual Probe): Verifies foundational principles and problem state assumptions.
    • Tier 2 (Strategic Formulation): Guides algorithmic design patterns and boundary condition setups.
    • Tier 3 (Diagnostic Clues): Pinpoints specific bugs and poses targeted questions for students to fix them.
  4. Active Response Verification: Verify student answers to Socratic inquiries, affirm correct deductions, and progress to deeper systems concepts.
  5. Empirical Benchmarking: Evaluate SocraticGuard against standard baseline LLMs across 30 standardized academic STEM problems.

5. Proposed System Architecture & Methodology

SocraticGuard is architected as an event-driven, four-stage pedagogical pipeline deployed through an interactive Streamlit graphical interface:

  1. Workspace & Code Ingestion: The learner enters or edits their code in a dedicated left-panel code editor, or asks questions via the conversational dialogue panel.
  2. Static & Semantic AST Analysis: Code passes through language-specific inspectors (src/code_inspector.py) that parse tokens, track function scopes, and locate syntax/logic errors.
  3. Pedagogical Prompt Synthesis & Anti-Cheating Filter: Solicitations for direct code solutions are intercepted. Dynamic system prompts enforce Bloom's Taxonomy Tier 3-5 (Apply & Analyze).
  4. Adaptive Response Delivery & Verification: SocraticGuard outputs diagnostic clues. When the student replies, their response is parsed and validated in real time.

  • Code Inspector Tests (28 tests): Validates C return values, format specifier mismatches, Python AST anti-patterns, and data science leakage.

9. Conclusion & Expected Impact

SocraticGuard demonstrates that generative AI can be transformed from an unconstrained homework oracle into an effective pedagogical tutor. By enforcing the Socratic method and identifying programming flaws through targeted diagnostic questions, the platform fosters independent problem-solving skills and preserves academic integrity.
